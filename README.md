# Simple chat + draw app

This project is a small realtime chat room with a shared background drawing board.

Features:
- random username on join
- roll dice to get a new name
- create or join room codes up to 10 characters
- realtime chat with timestamps
- shared canvas that all players in the room can draw on
- color picker and eraser
- room message history stored in memory

## Run it

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

Open multiple tabs or browsers to test the room with multiple players.
